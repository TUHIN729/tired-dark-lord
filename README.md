A 100-word villain monologue for the make.fun bounty "The Tired Dark Lord": Malachar of the Grey Mire, a dark lord worn down by the bureaucracy of his own evil — tithe ledgers, complaining drowned soldiers, a sun still to unmake — who only wants five minutes of silence before the next atrocity. The tiredness lives in the rhythm, the pauses and the deflections, never in a plain statement. The program writes the monologue to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
